# Chrome Web Store listing (draft)

**Name:** Petit Mot: learn French together
**Category:** Education
**Price:** Free. No ads, no in-app purchases.

**Short description (132 chars max):**
Learn French while you browse: gentle word swaps, Word Hunt games and family streaks. Free, private, 100% on your device.

**Description:**
Petit Mot turns the pages you already read into a playful French lesson for the whole family.

✨ Sprinkle French: with one click, a few English words on the page become French. Hover to peek at the meaning. Click to open a word card with le/la, the plural, a built-in French voice that works offline, and an example.
🔎 Word Hunt: French words hide in the page and you race to find them. Play solo, or pass the computer and challenge each other.
🔁 Smart review: a modern spaced-repetition scheduler (FSRS) brings each word back just before you would forget it.
🏡 Made for families: a "Who's learning?" picker, emoji avatars, a shared family streak with grace days, and a weekly leaderboard.
⚔️ Défi: challenge each other on the same computer, or send a code to someone on another computer.

🔒 Private by design: no accounts, no ads, no tracking, and the extension makes no internet connections of its own (the built-in voice plays from files inside the extension; online system voices are opt-in and labelled). Everything stays on your computer. It never runs on sign-in, payment, banking or email pages.

1,500 carefully chosen, kid-safe words, built from Lexique 3.83 and Wiktionary (CC BY-SA 4.0).

**Single purpose:** Help people learn French vocabulary while they read web pages.

**Permission justifications:**
- activeTab, scripting: change a few English words to French on the page you clicked Petit Mot on, and run the Word Hunt game there.
- storage: keep learners, progress and settings in the browser. When the user leaves sync on, a compact copy goes in chrome.storage.sync so Chrome can carry it between their own computers.
- sidePanel: show word cards, review, family leaderboard and challenges beside the page.
- offscreen: play the extension's own pronunciation audio files when a word is clicked on a web page.
- tts: optional system voices for pronunciation (on-device, or an online voice only if the user picks one); also the fallback if a built-in clip can't play.
- Optional host permissions, requested per site only when you turn on "Always sprinkle on this site": run automatically on that site.

**Data usage:** Does not collect or use any user data.
